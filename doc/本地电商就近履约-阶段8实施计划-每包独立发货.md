# 阶段8：每包独立发货（按包行过滤 fulfillment）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 `batchCreateFulfillment` 发货语义从「整单发货」升级为「按包发货」，使同一订单的多包裹可分仓分批发货，账本逐仓准确落账。

**Architecture:** 方案A（按包为主 + 整单降级）。`batchCreateFulfillment` 有 `packageId` 且 `linesJson` 非空 → 只发该包行；无 `packageId` 或 `OrderPackage`/`linesJson` 缺失 → 降级整单发货（告警不阻断）。`OrderPackageService` 新增 `findByOrderAndCode` 方法供复用。

**Tech Stack:** TypeScript, NestJS, TypeORM, Vendure Core, PostgreSQL

    result("t5.非拆单整单发货（降级兼容）", t5, shipItem5?.error ?? `trackId=${shipItem5?.trackId}`);
  } catch (e) {
    result("执行异常", false, e?.message ?? String(e));
  } finally {
    // 清理：取消测试单
    for (const o of orders) {
      await adminGql(
        `mutation{ transitionOrderToState(id: "${o.orderId}", state: "Cancelled"){ ... on Order { id state } ... on OrderStateTransitionError { message } } }`,

    }
    console.log(`\n结果: PASS ${passed} / FAIL ${failed} / SKIP ${skipped}`);

  }
})();
