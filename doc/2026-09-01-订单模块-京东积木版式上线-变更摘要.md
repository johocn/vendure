## 1. 本次变更一句话

订单详情页接入与商品详情一致的四级可回退风格体系，采用「京东搭积木」卡片式版式（默认 `jd`），旧版固定结构留存为 `classic` 备用模板，后端通过 Channel 自定义字段下发版式配置，前端缺省配置自动回退。

## 3. 四级可回退风格体系落地

| 层级 | 本期落地 |
|------|----------|
| L1 全局 token | 复用既有品牌色 / CSS 变量，未重构 |
| L2 页面级配置 | `orderDetailConfig` / `orderListConfig` 走 `GetChannelTheme` 下发 |
| L3 块级定制 | 块组件收 `block` prop（visible / title / text） |
| L4 兜底链 | 坏 JSON → null → `jd`；块显隐 → 内建 → true；文案 → locale → default → 首值；渲染器缺省回退 `OrderDetailJd` |

> 前端解析层缺省回退 `jd`，故前端可独立先上线（默认京东版式），后端字段仅影响「后台可配置 JSON」，不阻塞默认版式。

## 6. 后续可配置项（无代码改动）

在 Channel 自定义字段 `orderDetailConfig` 填写 JSON 即可热切换：

```json
{ "version": 1, "layout": "jd", "blocks": { "items": { "visible": true, "title": "商品清单" } } }
```

- `layout: "jd"` → 京东积木版式（默认）；`layout: "classic"` → 经典备用版式
- 任意块可设 `visible: false` 隐藏或定制 `title/text` 文案
