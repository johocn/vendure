# 阶段17 · 实施计划（商家店铺体系）

依据：`2026-08-21-本地电商就近履约阶段17设计-商家店铺体系.md`

对齐既有底座：`review-plugin` 已把商品评分聚合写入 `Product.customFields.reviewRating/reviewCount`（public，契约）；`marketplace-plugin` 用 `where: { customFields: { ... } }` 查询商品自定义字段（贴近该写法查询店铺商品）；新增 `Shop` 实体 + `Product.customFields.shopId`（int），与 marketplace 的 Seller/merchantRef 正交共存（字段按 name 幂等并入，互不冲突）。

## 执行顺序

### Step 1 — 实体：shop.entity.ts
- `Shop extends VendureEntity implements ChannelAware`：
  - `@Column({ type: 'varchar' }) name: string`
  - `@Column({ type: 'varchar', unique: true }) slug: string`
  - `@Column({ type: 'int', nullable: true }) logoAssetId: number | null`
  - `@Column({ type: 'int', nullable: true }) bannerAssetId: number | null`
  - `@Column({ type: 'text', nullable: true }) description: string | null`
  - `@Column({ type: 'varchar', default: 'applicant' }) status: string`（`applicant|active|closed`）
  - `@Column({ type: 'int', nullable: true }) ownerId: number | null`（店主后台账号，本阶段仅登记）
  - `@Column({ type: 'int' }) channelId: number`（普通列 NOT NULL，阶段16 教训——勿双声明 @ManyToOne）
  - `@ManyToMany(() => Channel) @JoinTable() channels: Channel[]`
- **评分不落列**：`rating/reviewCount/productCount` 来自 `Shop.customFields` 缓存 + `ShopRating` 实时重算。

### Step 2 — 类型：types.ts
- `ShopStatus = 'applicant' | 'active' | 'closed'`
- `ShopRating { rating: number; reviewCount: number; productCount: number }`
- `CreateShopInput { name, slug, logoAssetId?, bannerAssetId?, description? }`
- `UpdateShopInput`（同 Create 全部可选）
- `AssignProductsInput { shopId, productIds: [ID!]! }`
- `ShopListOptions { skip?, take? }`
- `ShopPluginOptions`（预留空接口）

### Step 3 — 自定义字段：shop-custom-fields.ts
- `Product.shopId`（`type: 'int'`, `nullable: true`, `public: true`，label zh_Hans）
- `Shop.shopRating`（`type: 'float'`, nullable）、`Shop.shopReviewCount`（int, nullable）、`Shop.shopProductCount`（int, nullable）——仅供读缓存，对外暴露在 `ShopRating` 型（public），勿设 public 防写入。

### Step 4 — 服务：shop.service.ts
- 注入：`TransactionalConnection`、`ListQueryBuilder`、`ProductService`、`ChannelService`。
- 管理端：
  - `createShop(ctx, input)`：slug 唯一校验（重复抛 `UserInputError`）→ 落库 `status='applicant'`、`channelId=ctx.channelId`。
  - `updateShop(ctx, id, input)`、`setShopStatus(ctx, id, status)`（`applicant→active→closed`，校验合法迁移，非法抛 `UserInputError`）。
  - `assignProductsToShop(ctx, input)`：批量置 `product.customFields.shopId = shopId`（`productService.update`，逐条或批量），随后 `recomputeShopRating`。
  - `unassignProductsFromShop(ctx, input)`：置 `shopId = null`，随后 `recomputeShopRating`。
  - `shops(ctx, options)` / `getShop(ctx, id)`：管理端列全部状态。
- C 端：
  - `getActiveShops(ctx, options)`：仅 `status='active'`。
  - `getShopBySlug(ctx, slug)`：按 slug 查，仅 active 返回，否则 `undefined`。
  - `getShopProducts(ctx, shopId, options)`：`productService` 下按 `Product.customFields.shopId` 过滤（写法对齐 marketplace：`where: { customFields: { shopId } }`），`listQueryBuilder` 分页。
  - `getShopRating(ctx, shopId)`：**实时扫描**该店归属商品的 `customFields.reviewRating/reviewCount` → 加权平均 `rating`（`Math.round(avg*10)/10`）、`reviewCount` 求和、`productCount` 计数。
- `recomputeShopRating(ctx, shopId)`：同上实时口径 → 写 `Shop.customFields.shopRating/shopReviewCount/shopProductCount`（须经 `shopService?` 或 `connection` 用**新对象** patch 生成新引用写库，阶段10 `updateCustomFields` 教训）。
- 鉴权：管理端 mutation 用 `@Allow(Permission.Settings)`；C 端查询 `@Allow(Permission.Public)`。

### Step 5 — Resolver
- `shop-admin.resolver.ts`：`createShop/updateShop/setShopStatus/assignProductsToShop/unassignProductsFromShop`（Mutation），`shops/shop`（Query），`Shop.products` ResolveField。
- `shop-shop.resolver.ts`：`shops/shop`（Query，仅 active），`Shop.rating` ResolveField（实时 `getShopRating`，返回 ShopRating 型），`Shop.products` ResolveField（分页店铺商品）。

### Step 6 — 插件：plugin.ts
- `entities: [Shop]`、`providers: [ShopService]`、`adminApiExtensions` + `shopApiExtensions`（两个 Resolver）。
- `configuration`：`mergeCustomFields`（本地实现，得名幂等并入）：
  - `config.customFields.Product` 并入 `shopId`（int, nullable, public）。
  - `config.customFields.Shop` 并入 `shopRating/shopReviewCount/shopProductCount`（nullable）。
- Shop schema：
  - `type Shop implements Node { id, name, slug, logoAssetId, bannerAssetId, description, status, rating: ShopRating!, productCount: Int! }`
  - `type ShopRating { rating: Float!, reviewCount: Int!, productCount: Int! }`
  - `input CreateShopInput/UpdateShopInput/AssignProductsInput`、`input ShopListOptions { skip, take }`
  - `extend type Query`: `shops(options): [Shop!]!`、`shop(slug: String!): Shop`
  - `extend type Product`：`shop`（`product.customFields.shopId` 解析到 Shop，可空）
- Admin schema：
  - `Shop` 型 + `Shop.products`（PaginatedList）
  - `extend type Mutation`: `createShop/updateShop/setShopStatus/assignProductsToShop/unassignProductsFromShop`（后两者返回 Boolean）
  - `extend type Query`: `shops/shopById(id)`（`shop` 与 C 端同名 dev 兼容，Admin 端用 `shopById` 规避重名）

### Step 7 — 工程脚手架（对齐 review-plugin）
- `vitest.config.mts`、`tsconfig.build.json`、`package.json`（`main: lib/index.js`、`types`、`exports`）。
- `index.ts` 导出 `ShopPlugin`、`Shop` entity、types。
- `e2e/shop.e2e-spec.ts`（含 `e2e/__data__/`，sqljs 缓存库）。

### Step 8 — e2e 用例（标题含中文）

| # | 用例 | 断言要点 |
|---|---|---|
| 1 | 插件可加载；Product.shopId 字段默认 null | 商品 shop 为 null；无店铺时 `shops` 空 |
| 2 | 开店与审核：admin 创 applicant → setShopStatus active | C 端 `shops` 出现该店；`closed` 不对外 |
| 3 | 商品归属：assignProductsToShop 后商品归店 | 店铺商品列表含该商品；`product.shop` 指向店铺 |
| 4 | 解绑：unassignProductsFromShop 移除 | 商品离开店铺列表；productCount 减 |
| 5 | 店铺评分聚合：给归属商品写 reviewRating/reviewCount → recompute | `shop(id).rating` 加权平均、reviewCount 求和、productCount 正确 |
| 6 | 店铺主页：`shop(slug)` 返回档案+评分+商品数+商品列表 | shop(slug) 字段齐全；slug 不存在返回 null |
| 7 | 校验与越权：slug 重复建店被拦截；未授权 mutation 被 Forbidden | 抛错/403 |
