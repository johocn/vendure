## 2. 实施步骤

### Step 1: flash-sale-runtime.ts（新增）
```ts
import { TransactionalConnection } from '@vendure/core';
let connection: TransactionalConnection | undefined;
export function setFlashSaleConnection(conn: TransactionalConnection): void { connection = conn; }
export function getFlashSaleConnection(): TransactionalConnection {
    if (!connection) throw new Error('FlashSalePlugin TransactionalConnection not initialized');
    return connection;
}
```

### Step 2: flash-sale-promotion-condition.ts（重写）
- `check`（async）：读 `order.customFields.flashSaleActivityId` → 运行时查活动 → 校验：
  - 活动存在
  - `status === 'active'`（非 active 不优惠）
  - 窗口：`startAt ≤ now ≤ endAt`
  - 库存：`soldCount < totalStock`（卖光不优惠）
  - 返回 `{ activityId, variantId: activity.variantId, flashPrice: activity.flashPrice }`
- `priorityValue: 950`

### Step 3: flash-sale-price-action.ts（重写）
- `PromotionItemAction`，`conditions: [flashSaleDiscountCondition]`
- `execute(ctx, orderLine, _args, state)`（async）：
  - `const s = state.flash_sale_discount`；无 `flashPrice` → 0
  - `orderLine.productVariant?.id !== String(s.variantId)` → 0
  - `unitPrice = pricesIncludeTax ? orderLine.unitPriceWithTax : orderLine.unitPrice`
  - `delta = unitPrice - flashPrice`；`delta > 0 ? -delta : 0`

### Step 4: flash-sale.service.ts（修改）
- `init(injector)` 增加 `setFlashSaleConnection(this.connection)`
- 新增 `applyFlashSale(ctx, activityId): Promise<Order>`：
  1. 重载 order（含 lines.productVariant）；校验订单包含秒杀变体行
  2. 加载活动；校验存在、`active`、窗口
  3. **限购**：`findByCustomerId` 该客户订单过滤同活动且非 Cancelled，数量 ≥ `limitPerUser` → 抛 `Purchase limit exceeded`
  4. **原子占库存**：`qty` = 订单内秒杀变体行总件数；DB fallback `UPDATE soldCount+=qty WHERE ... AND soldCount+qty<=totalStock`（Redis 走 `reserveStock`）；受影响=0 → 抛 `Sold out` 并回滚限购预占
  5. 写订单字段 `updateCustomFields(ctx, orderId, { flashSaleActivityId, flashSaleStartAt, flashSaleEndAt })` + `applyPriceAdjustments`
  6. `soldCount >= totalStock` → 置 `ended`
  7. 返回订单
- 修正 `releaseStock(ctx, activityId, quantity)`：DB 回滚 `WHERE soldCount - qty >= 0`

### Step 5: flash-sale-shop.resolver.ts（修改）
- 新增 `@Mutation() applyFlashSale(@Ctx() ctx, @Args('activityId') id: ID): Promise<Order>`，委托 `FlashSaleService.applyFlashSale`

### Step 6: plugin.ts（修改）
- `onApplicationBootstrap`：`init` 已会 `setFlashSaleConnection`
- 移除 `flashSaleEligibilityCondition`（promotionConditions 只留 `flashSaleDiscountCondition`）
- shop schema 新增 `applyFlashSale(activityId: ID!): Order`
- 取消回滚事件：`releaseStock(ctx, activityId, <按订单秒杀行总件数>)`（不在事件里 `totalQuantity`，由 service 精确计算）

### Step 7: e2e（重写）
- 复用 group-buy e2e 模式：`customerCount: 2`、`testSuccessfulPaymentMethod`、`pricesIncludeTax: true`
- 创建一张无参数促销「秒杀价」= `flash_sale_discount` + `flash_sale_price`
- 场景：见设计 §7（8 用例）
- 状态机：建 startAt 未来 → `upcoming`；把 startAt/endAt 改到过去再等定时任务或直接改状态验证（e2e 用 admin `updateFlashSaleActivity` 改时间 + 手动驱动，确定性）
