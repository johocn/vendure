# 阶段21 · 实施计划（收货地址 + 按店配送范围）

依据：`2026-08-21-本地电商就近履约阶段21设计-收货地址配送范围.md`

核心：新插件 `delivery-plugin`，`DeliveryAddress` C端地址簿 + `DeliveryRange` 按店配送范围，`validateDelivery` 按店地理校验（haversine / 省市区白名单）。

## 执行顺序

### Step 1 — 插件骨架
- 新建 `packages/delivery-plugin/`（package.json/tsconfig.json/tsconfig.build.json/vitest.config.mts/index.ts），peer `@vendure/core`；devDep 同 operation-plugin。
- `src/constants.ts`（loggerCtx='DeliveryPlugin'、DELIVERY_PLUGIN_OPTIONS）。

### Step 2 — 实体
- `src/delivery-address.entity.ts`：`DeliveryAddress`，列见设计；`@Index(['customerId','isDefault'])`；ChannelAware（channelId 普通列 NOT NULL + ManyToMany Channel）。
- `src/delivery-range.entity.ts`：`DeliveryRange`，`@Index(['shopId','channelId'], { unique: true })`；rangeType varchar NOT NULL default 'all'；districtCodes 存 JSON 文本；ChannelAware。
- Date/pit 对齐阶段11铁律。

### Step 3 — 服务 delivery.service.ts
- 注入 TransactionalConnection + CustomerService。
- `requireCustomer(ctx)`：Unauthorized/NotFound 口径（review 同款）。
- 地址簿 CRUD + setDefault（事务内先清默认再置目标，唯一默认）。
- 范围 `getRange`/`upsertRange`（按 shopId+channelId 存在则 update 否则 insert）。
- `validateDelivery(ctx, {address, shopIds})`：逐店结果 `{shopId, inRange, reason}`，规则见设计；`haversineKm` 工具。
- 复用 shop-plugin `Shop`（lib 引用）仅作范围归属校验（存在性），repository 直接取。

### Step 4 — 双 schema + resolver
- `src/delivery-shop.resolver.ts`：地址簿 5 个 Auth mutation/query；`shopDeliveryRange`/`validateDelivery` Public。
- `src/delivery-admin.resolver.ts`：`deliveryRange`/`upsertDeliveryRange`，`@Allow(Permission.UpdateSettings)`。
- types 在 plugin.ts adminSchema/shopSchema 定义（DeliveryAddress / DeliveryRange / DeliveryResult / inputs）。

### Step 5 — plugin.ts
- imports PluginCommonModule；entities `[DeliveryAddress, DeliveryRange]`；providers `DeliveryService`；admin/shop extensions 挂 resolver；`DeliveryPlugin.init(options)` 工厂导出。

### Step 6 — 工作区
- workspaces `packages/*` 自动纳入；跨插件 Shop 用 lib 引用；package-lock 如需 install 则更新（本插件新增 peer 仅 core，通常无需改 lock）。

### Step 7 — e2e（≥10 用例）
- 复用骨架：`createTestEnvironment` + plugins `[ShopPlugin.init({}), DeliveryPlugin.init({})]`；admin 建店并 active。
- 用例：
  1. 插件加载；未登录查 myDeliveryAddresses 报 Unauthorized
  2. 建地址（含省市区/坐标），首条自动默认，列出含默认
  3. 建第二地址后 setDefault 切换（默认唯一）
  4. update 地址
  5. delete 地址
  6. 越权隔离：用户 B 看不到/删不了 A 的地址
  7. admin upsert circle 范围并读取
  8. circle 校验：近点 inRange true / 远点 false
  9. district 校验：命中白名单 true / 未命中 false
  10. rangeType 'all' 不限 true；未启用/未配置 NO_DELIVERY false
  11. 多店聚合：一店可达一店不可 → 结果含 false（整单不可达）
- 运行：插件目录 `$env:PACKAGE='delivery-plugin'; npx vitest run --config vitest.config.mts e2e/delivery.e2e-spec.ts`；改实体删 `__data__/*.sqlite`。

### Step 8 — 构建
- `node node_modules/typescript/bin/tsc -p packages/delivery-plugin/tsconfig.build.json`。
