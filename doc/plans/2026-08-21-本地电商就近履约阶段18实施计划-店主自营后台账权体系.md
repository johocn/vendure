# 阶段18 · 实施计划（店主自营后台账权体系）

依据：`2026-08-21-本地电商就近履约阶段18设计-店主自营后台账权体系.md`

核心：店主=Administrator + 自定义权限 Role + `Shop.administratorId` 归属，全部数据按 shopId 隔离，越权 Forbidden。

## 执行顺序

### Step 1 — 实体：Shop.administratorId
- 将 `ownerId` 更名 `administratorId`（`@Column int nullable`），语义存 Administrator.id。
- e2e/生产 `synchronize` 自动建/加列；`ownerId` 本为占位未用，安全更名。

### Step 2 — 自定义权限
- 新建 `merchant-permissions.ts`：`export const manageOwnShop = new PermissionDefinition({ name: 'ManageOwnShop' })`。
- plugin `configuration` 幂等并入 `config.authOptions.customPermissions`（按 name 去重）。

### Step 3 — 服务：shop.service.ts（新店主域）
- 注入 `AdministratorService`、`RoleService`。
- 解析：`resolveShopFromActiveUser(ctx)` → `Administrator`(where `user.id===activeUserId`)[0] → `Shop`(where `administratorId===admin.id, status==='active'`)。
- 平台：`provisionShopOwner(ctx, shopId, input)`（建店主 Role 幂等 → `administratorService.create` → 写 shop.administratorId）。
- 店主：
  - `requireMyShop(ctx)`（无/非 active → Forbidden）。
  - `getMyShop` / `updateMyShop`（禁 slug/status）。
  - `getMyShopProducts`(复用 getShopProducts) / `addProductToMyShop`（set shopId=myShop，校验商品归属无冲突）·`removeProductFromMyShop`（仅能移我店商品）·`updateMyShopProduct`（校验归属后更新 name/description translations）。
  - `getMyShopOrders` / `getMyShopOrder`（按 OrderLine.productVariant.product.shopId 聚合我店行 → 投影 MerchantOrder，items 仅我店行）。
  - `getMyShopReviews`（我店商品评价列表）/ `approveMerchantReview` / `rejectMerchantReview`（校验 review.productId ∈ 我店商品 → 改 status + 该商品评分重算）。

### Step 4 — 店主评分重算（复用 review 口径）
- shop-plugin 内 `recomputeMerchantProductRating(ctx, productId)`：approved 主评(`parentId IS NULL`)加权 → 写 `Product.customFields.reviewRating/reviewCount`（Phase 12/16 修正口径）。与 review-plugin 同口径。

### Step 5 — merchant-resolver.ts（ADMIN API）
- 全部 `@Allow(manageOwnShop.Permission)`（`provisionShopOwner` 用 `Permission.UpdateSettings`）。
- Query/Mutation 按设计清单；每方法先 `requireMyShop(ctx)`。

### Step 6 — plugin.ts / schema
- adminApiExtensions 增 `merchant-resolver`。
- 新增类型：`CreateOwnerInput`/`UpdateMyShopInput`/`UpdateMyShopProductInput`/`MerchantOrder`/`MerchantOrderLine`/`MerchantReview`。
- Query：myShop / myShopProducts / myShopOrder / myShopOrders / myShopReviews。
- Mutation：provisionShopOwner / updateMyShop / addProductToMyShop / removeProductFromMyShop / updateMyShopProduct / approveMerchantReview / rejectMerchantReview。

### Step 7 — package.json peer 依赖
- 加 `"@vendure/review-plugin": "0.0.1"`（仅 import `Review` 实体）。

### Step 8 — e2e（9 用例）
- 复用阶段17 e2e 骨架；config 加 `[ShopPlugin.init, ReviewPlugin.init]` + `customFields.Product` 评分字段（或 review-plugin 自带）+ `authOptions.customPermissions`（ShopPlugin 已注册）。
- `adminClient.asSuperAdmin()` 建店/审核/provision；`adminClient.asUserWithCredentials(merchantEmail, merchantPass)` 切店主；`asSuperAdmin()` 切回。
- 建单：`shopClient` 用已归属商品下单支付（复用阶段16 支付方式）生成我店订单行；再建他人店商品订单验证行投影隔离。
- 越权用例：店主 A 查店主 B 的 shop/product/myShopOrder → Forbidden/空；查全局 `products` → Forbidden。

### Step 9 — 构建 + 跑绿
- `node node_modules/typescript/bin/tsc -p packages/shop-plugin/tsconfig.build.json`。
- 插件目录内 `$env:PACKAGE='shop-plugin'; npx vitest run --config vitest.config.mts e2e/shop-merchant.e2e-spec.ts`。
- 改实体 schema 删 `e2e/__data__/*.sqlite` 重跑。
