## 2. 实施步骤

### Step 1: order-custom-fields.ts + channel-custom-fields.ts
- Order：`pointsToRedeem`(int, default 0) / `pointsRedeemAmount`(int, default 0)，均 public
- Channel：`pointsPerYuan`(int, default 100) / `pointsExpireDays`(int, default 0)

### Step 2: points-redeem-condition.ts + points-redeem-action.ts
- condition `check`（async）：读 `order.customFields.pointsToRedeem > 0` 且 `pointsRedeemAmount > 0` → 返回 `{ pointsToRedeem, pointsRedeemAmount }`；否则 false
- action `execute`（PromotionOrderAction）：读 state 返回 `-min(pointsRedeemAmount, order.subTotalWithTax)`

### Step 3: member-level.service.ts 补逻辑
- `redeemPoints(ctx, points)`：见设计 4.1（绑定即扣，原子扣减 + SPEND 明细 + 写订单字段 + 重算价格）
- `releasePointsByOrder(ctx, order)`：取消回退（EARN 明细 remark=`order_cancelled:<orderId>`，清字段）
- `refundPointsByOrder(ctx, order, refund)`：按比例回退（EARN 明细 remark=`refund_settled:<refundId>`）
- `expireEarnedPoints(ctx)`：扫描过期 EARN → 幂等扣余额 + EXPIRE 明细
- `addPoints` 增可选 `expiresAt?: Date` 参数

### Step 4: plugin.ts 接线
- 注册 Promotion 条件/动作、merge customFields（Order + Channel）
- 事件：Delivered 加 expiresAt 落库；Cancelled 回退；Refund Settled 按比例回退
- ScheduledTask：每 5 分钟 `expireEarnedPoints`
- shop schema 增 `redeemPoints(points: Int!): Order!`

### Step 5: e2e（8 用例）
见设计文档 §6。参照 `flash-sale.e2e-spec.ts` 的 testConfig + PACKAGE 环境变量方式。
