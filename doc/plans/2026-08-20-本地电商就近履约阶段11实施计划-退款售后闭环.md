# 阶段11 实施计划：退款/售后闭环

> 依赖：阶段10（Completed 订单状态 + 自动/手动完成）。所有库改动本地构建后提交 dist。

## 分步任务

### T1. dummy 支付处理器补 createRefund（开发验证）
- 文件：`packages/core/src/config/payment/dummy-payment-method-handler.ts`
- 新增 `createRefund` 方法，返回 `{ state: 'Settled', transactionId: <随机>, metadata: { simulated: true } }`，使虚拟订单退款能走到 Settled 终态。
- 可选：读 `metadata.shouldDeclineRefund` 模拟退款失败（Failed），供 e2e 失败重试场景。

### T2. 订单自定义字段 fulfillmentCompletedAt
- 文件：`packages/logistics-plugin/src/catalog-custom-fields.ts`
- 新增 Order 自定义字段 `fulfillmentCompletedAt`（datetime，public），在 `confirmOrderReceipt` / 自动完成扫描把订单转 Completed 时落库（复用 `markDeliveredAt` 同款 `updateCustomFields` 模式，新加 `markCompletedAt`）。

### T3. after-sales 状态机 + 实体 + SDL
- `packages/after-sales-plugin/src/types.ts`：`AfterSalesState` 增 `RefundFailed`；`Received: ['Refunded','RefundFailed']`，`RefundFailed: ['Refunded']`。
- `packages/after-sales-plugin/src/after-sales-request.entity.ts`：加 `refundTransactionId` / `actualRefundAmount` / `refundedAt` / `refundError` 列（均 nullable，timestamp 跨库兼容）。
- `packages/after-sales-plugin/src/plugin.ts`：Shop/Admin SDL 的类型 + `AfterSalesState` 枚举补 `RefundFailed`；Admin 增 `retryAfterSalesRefund(id)` mutation。

### T4. processRefund 退款结算闭环
- 文件：`packages/after-sales-plugin/src/after-sales.service.ts`
- `processRefund` 重写：
  1. 前置校验 `order != null`、state 为 `Received`、有支付；
  2. 事务内 `refundOrder` → 拿到 `Refund`（可能 Pending）；
  3. 若 Refund 为 Pending 且未 Failed，`orderService.settleRefund({ id, transactionId })` 推进到 Settled；
  4. 校验 Refund 状态：`Settled` → 更新 request 字段（refundTransactionId/actualRefundAmount/refundedAt）并把 state 置 `Refunded`；`Failed` → 置 `RefundFailed` + 记录 refundError，**不抛；**
  5. 回写 `Order.customFields.afterSalesStatus`。
- 新增 `retryAfterSalesRefund(id)`：仅从 `RefundFailed` 允许，复用 processRefund 内部逻辑。

### T5. Completed 售后入口
- 文件：`packages/after-sales-plugin/src/after-sales.service.ts`
- `createRequest` allowedStates 加 `'Completed'`；
- 售后期起点优先取 `order.customFields.fulfillmentCompletedAt ?? order.customFields.fulfillmentDeliveredAt ?? order.updatedAt`。

### T6. e2e
- 文件：`packages/after-sales-plugin/e2e/after-sales.e2e-spec.ts`（沿用已有 sqlite 结构）
- 覆盖：Completed 发起售后 / 售后期限制 / 全链路退款→Refunded→Refund=Settled / 库存回补 / 退款失败重试 / 越权。
