## T1 · 实体与常量（coupon-plugin/src）
- 新建包目录 `packages/coupon-plugin`（拷贝 after-sales-plugin 的 package.json/tsconfig/vitest 骨架）。
- `constants.ts`：`COUPON_PLUGIN_OPTIONS`、`loggerCtx = 'CouponPlugin'`。
- `coupon-template.entity.ts`：
  - 字段按设计 §3.1；`channels` ManyToMany（ChannelAware）。
  - `type` varchar、`enabled` boolean 默认 true、`claimedCount` int 默认 0。
  - 日期列用**可选 `Date`** 模式（`@Column({ nullable:true }) startsAt?: Date`）。
- `customer-coupon.entity.ts`：
  - 字段按设计 §3.2；`code` varchar 唯一索引 `Index({ unique:true })`。
  - `status` varchar 默认 `UNUSED`；`reservedOrderId`/`usedOrderId` honest nullable int。
- `types.ts`：`CouponType = 'FIXED'|'PERCENT'|'FULL'`；`CouponStatus = 'UNUSED'|'USED'|'RETURNED'|'EXPIRED'|'INVALID'`；`CouponPluginOptions`。

## T2 · Promotion 条件 + 动作（结算套用）
- `coupon-promotion-condition.ts`：`new PromotionCondition`，`code:'coupon_applied'`。
  - `check(ctx, order)`：读 `order.customFields.couponCode` 非空；调 service 校验券仍有效、模板 enabled、未过期、`minSpend<=subTotal`.
- `coupon-promotion-action.ts`：
  - 方案：`new PromotionOrderAction` `code:'coupon_discount'`，读出券模板按 type 折算：
    - `FIXED`/`FULL`：`-Math.min(discountValue, upperBound)`（对齐 `order_fixed_discount` upperBound 用 `subTotalWithTax|subTotal`）。
    - `PERCENT`：`-Math.round(subTotal * discountValue/100)`（如 8.5折 = discountValue 85 = 15% off）。
  - 若查不到券模板（异常态）返回 0，避免负向加价。
- `order-custom-fields.ts`：`Order[ {name:'couponCode',type:'string',nullable:true}, {name:'couponId',type:'int',nullable:true} ]`。
- 插件 `configure()`：`mergeCustomFields` + push conditions (`coupon_applied`) + actions (`coupon_discount`)。

## T3 · CouponService（核心业务）
- `coupon.service.ts`，`init(injector)` 注入 `OrderService`（阶段8/9 约定）。
- 方法：
  - `findTemplate(s)/findOneTemplate`
  - `createTemplate/updateTemplate`（白名单字段，`enabled` 可改）/`deleteTemplate`
  - `claimCoupon(ctx, templateId)`：原子扣量（affected 校验）→ perUserLimit 校验 → 生成唯一 `code`（重试兜底冲突）→ 存 UNUSED。
  - `grantCoupon(ctx, templateId, customerIds)`：定向发券（不扣 claimCount，或复用同一原子扣量，二选一，建议**发券也扣发行余量**保持一致）。
  - `applyCouponToOrder(ctx, orderId, code)`：校验为本人/UNUSED/未过期/模板 enabled/`minSpend<=subTotal` → `orderService.updateCustomFields(ctx, orderId, {couponCode,couponId})`。
  - `clearCouponFromOrder(ctx, orderId)`：清空自定义字段。
  - `bindAsUsed(ctx, code, orderId)`：核销（OrderPlacedEvent 触发）。
  - `returnCoupon(ctx, code, orderId)`：幂等回退（USED+usedOrderId=本单 → RETURNED）。
  - `listMyCoupons/bookCentre`、`listAllCoupons`（admin）。

## T5 · e2e 验收（packages/coupon-plugin/e2e/coupon.e2e-spec.ts）
- 沿用 after-sales e2e 的 testConfig 骨架（sqljs、单个 payment handler `testSuccessfulPaymentMethod`）。
- 用例（共 ~6-7 条，覆盖设计 §7）：
  1. 满减券全链路（建→领→选券→订单 -20→支付→USED→usedOrderId 落单）
  2. 折扣券金额核算（含含税场景）
  3. 防超发（totalCount 边界）+ perUserLimit 超领失败

  6. 未达门槛/非本人/已用券不可选
- 注意：e2e 直接 import `../src/plugin`（source），logistics/inventory 等依赖用 lib。

## 风险与对策
| 风险 | 对策 |
|------|------|
| 一单多券叠加复杂 | 本阶段只支持一单一券，`applyCouponToOrder` 先清旧再覆写 |
| 并发领券超发 | 原子 UPDATE 扣量 + 唯一码索引 |
| Promotion 金额临界（如 PERCENT 取整） | 与 core `order_percentage_discount` 对齐取整规则，e2e 固化 |
| 核销/回退破坏主流程 | 状态前置校验 + 只 `Logger.warn` 不抛（仿 flash-sale event 订阅） |
| 跨库日期列 | 实体一律可选 `Date` 模式（阶段11 铁律） |
