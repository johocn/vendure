# 阶段19 · 实施计划（收藏/关注系统）

依据：`2026-08-21-本地电商就近履约阶段19设计-收藏关注系统.md`

核心：新插件 `favorite-plugin` + `Favorite` 实体 + toggle/列表/计数 C 端 API，纯 shop-api 登录态。

## 执行顺序

### Step 1 — 插件骨架
- 新建 `packages/favorite-plugin/`（tsconfig、package.json，peer 依赖 `@vendure/core`、`@vendure/shop-plugin`，devDependencies 同 review-plugin）。
- `src/constants.ts`（loggerCtx、FAVORITE_PLUGIN_OPTIONS）。

### Step 2 — 实体 Favorite
- `src/favorite.entity.ts`：`customerId/productId/shopId/channelId/createdAt`；复合唯一 `(customerId, productId)` 与 `(customerId, shopId)`。
- `Date` 列遵守阶段11铁律：`@Column({ nullable: true }) createdAt?: Date`（勿写死 type）。

### Step 3 — 服务 favorite.service.ts
- 注入 `TransactionalConnection`、`CustomerService`、`ProductService`、`ShopService`（`@vendure/shop-plugin` lib）。
- `requireCustomer(ctx)`：复用 review 口径（activeUserId 判空 → `customerService.findOneByUserId` → Unauthorized/NotFound）。
- toggle 收藏/关注（判存在→删 false / 建 true），并维护计数。
- 计数：`Product.customFields.favoriteCount` 写回（favorite-plugin 自注册该 customField，`getRepository(Product)` 微更新）；店铺关注数按 `count({shopId})` 动态聚合（不写 shop-plugin 缓存列，解耦）。
- 列表：`myFavoriteProducts`/`myFollowedShops` join 后返回目标详情。

### Step 4 — C 端 schema + resolver
- `src/favorite.resolver.ts`（shop-api，全部 `@Allow(Permission.Authenticated)`，先 `requireCustomer`）。
- Query：`myFavoriteProducts`/`myFollowedShops`/`isProductFavorite`/`isShopFollowed`。
- Mutation：`toggleFavoriteProduct`/`toggleFollowShop`。
- `Product.favoriteCount`/`Shop.followerCount` 走 plugin `configuration` 的 `mergeCustomFields`（对齐阶段18幂等并入）。

### Step 5 — plugin.ts / schema / factory（builder）
- `plugin.ts`：imports `PluginCommonModule`，entities `[Favorite]`，providers `FavoriteService`，shopApiExtensions 挂 resolver，configuration 幂等并入 customFields。
- `index.ts/builder.ts` 导出 `FavoritePlugin`（静态 `init`）+ `Favorite` 实体。

### Step 6 — package.json / tsconfig
- 注册到工作区（根 `package.json` workspaces/依赖映射、`package-lock` 由 install 更新）。
- 根 `tsconfig.base.json` paths 若需要补 `@vendure/favorite-plugin`。

### Step 7 — e2e（≥7 用例）
- 复用阶段17/18 e2e 骨架：`createTestEnvironment`，plugins `[ShopPlugin.init(), FavoritePlugin.init()]` + `customFields.Product` 评分字段 + shop-api 登录。
- 用例：未登录 401 / 收藏商品 toggle 幂等 / 收藏列表与 isFavorite / 取消收藏 / 关注店铺 toggle / 关注列表与 isFollowed / 越权隔离（A 看不到 B 的收藏）。
- 运行方式：插件目录内 `$env:PACKAGE='favorite-plugin'; npx vitest run --config vitest.config.mts e2e/favorite.e2e-spec.ts`；改实体后删 `e2e/__data__/*.sqlite`。

### Step 8 — 构建 + 跑绿
- `node node_modules/typescript/bin/tsc -p packages/favorite-plugin/tsconfig.build.json`。
- 全绿后本地上库（lib 入库，遵循部署铁律）。

### Step 9 — 提交推送 + 记忆
- commit：`feat(favorite-plugin): 阶段19 收藏/关注系统（商品收藏+店铺关注 toggle/列表/计数，登录态隔离）`
- 推送 origin/master；更新 project_memory「阶段19」段落。

## DoD
- e2e ≥7 用例全绿；lib 构建入库；服务器 `git pull + pm2 restart` 即上线（不在服务器构建）。
