# 阶段45 实施计划：发票通知触达 + 后台发票中心 + 红冲/作废增强

> 目标：承接阶段44「行级明细快照 + 批量/自动开票 + 抬头复用 + 统一发票号」，补齐发票域剩余三项运行能力（阶段44计划第4节方向2/3/4，**除对接真实发票服务商**）：
> ① 发票开具/红冲/作废状态变更 → 消息中心 push 触达（复用阶段23 message-plugin 通道）；
> ② 后台发票中心 UI（列表/筛选/批量开票/导出 Excel，替代 GraphQL 手工调用）；
> ③ 红冲/作废增强（部分红冲、作废留痕、红冲后重开同一订单）。
> 现状：invoice-plugin 已具备 PENDING/ISSUED/REVERSED/FAILED 四态、`reverseInvoice`（仅支持全量红冲且要求 ISSUED）、`createInvoice` 重复校验排除 REVERSED/FAILED；message-plugin 提供广播式 `sendMessage`/消息中心（`myMessages`）与 push 通道；dashboard SDK（`packages/dashboard`）支持 `routes` + `dataTables` + `pageBlocks` 自定义路由。**缺**：单客户即时通知、后台列表中心与导出、部分红冲/作废留痕。

## 1. 范围与验收

### A. 发票状态通知触达（方向2，复用 message-plugin）
- message-plugin `MessageService` 新增 `pushToCustomerByUserId(ctx, userId, title, body, deliveryChannel='inapp')`：按 user.id 解析 Customer，向该客户写入 `Message` + `MessageDelivery(sent)`（进 C 端消息中心）；`deliveryChannel='push'` 时额外调 `MessagePushService.sendPush`。MessagePlugin `exports: [MessageService]`。
- invoice-plugin `imports: [MessagePlugin]`，`InvoiceService` 懒注入 `MessageService`（未装则通知跳过，不阻塞开票）。
- 通知时机（异步、失败不阻塞主流程）：开票成功 `ISSUED`、全量红冲 `REVERSED`、部分红冲、作废 `VOIDED`。
- **验收**：开票成功 → 该客户 `myMessages` 出现「发票已开具 INV-xxx」；内容含发票号/金额/状态。

### B. 后台发票中心 UI + 导出（方向3）
- admin schema：`Invoice` 增字段（见A）+ `Query.exportInvoicesCsv(options): String!` 返回带 BOM 的 CSV 文本（兼容 Excel）。
- dashboard 新增自定义路由 `/invoices`（导航挂到 sales 区）：数据表列出发票（状态/类型/抬头/金额/发票号/时间），支持状态筛选、多选 + 批量开票（`bulkIssueInvoices`）、单张操作（开票/红冲/作废，弹确认录入原因）、导出 CSV 下载。
- **验收**：admin 页面能筛选 PENDING 并批量开票、能红冲/作废留痕、能下载含明细的 CSV。

### C. 红冲/作废增强（方向4）
- `InvoiceStatus` 增 `VOIDED='voided'`；实体增 `voidedAt/voidReason/parentInvoiceId/isRed/reversedAmount`。
- `voidInvoice(id, reason)`：仅 PENDING/FAILED → VOIDED（作废留痕：voidReason/voidedAt，list 保留记录）。
- `reverseInvoice(id, reason, reverseAmount?)`：不传或 `>=amount` → 全量红冲（现状）；`0<reverseAmount<amount` → **部分红冲**：生成一条红字发票（`isRed=true, parentInvoiceId=原票, status=REVERSED, amount=-reverseAmount`），原票记 `partiallyReversed=true, reversedAmount+=reverseAmount`，状态保持 ISSUED。
- `createInvoice` 重复校验排除 VOIDED（同 REVERSED/FAILED），支持**红冲/作废后重开同一订单**（已排除 REVERSED；新增排除 VOIDED）。
- **验收**：PENDING 作废留痕并允许重开；部分红冲生成红字票且金额为负、原票可再补红；全量红冲后重开成功。
