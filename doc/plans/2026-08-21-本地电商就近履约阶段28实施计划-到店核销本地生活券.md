# 阶段28 到店核销 / 本地生活服务券 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新建 `@vendure/voucher-plugin`，让商家把到店服务作为服务型商品销售，用户下单获得到店券，店主本人扫码/输码核销，支持直核销+预约双模式，完整衔接订单/退款/结算/店铺体系。

**Architecture:** 复用既有插件四件套（package.json/tsconfig/vitest/index）+ admin/shop 双 API schema + local `tsc` 产物入库。实体 `ServiceVoucher`（到店券，幂等唯一）+ `VoucherBooking`（预约档，仅预约品类）。服务型商品 `Product.customFields.serviceType` 标记 → 下单免配送/免物流/免库存 → PaymentSettled 自动生成券。店主域鉴权复用阶段18。

**Tech Stack:** Node + NestJS + TypeORM + Vendure core/shop-plugin/address-plugin + vitest (e2e, sqljs)。

## 契约/命名速查（跨任务一致）

- 店主域鉴权 `requireMyShop(ctx)`：`administratorService.findOneByUserId(ctx, ctx.activeUserId)` → `getRepository(ctx, Shop).findOne({administratorId})` + `status==='active'`，否则 `ForbiddenError`。
- 券 `status`: `usable | used | expired | refunded | voided`；预约 `status`: `booked | visited | noShow | cancelled`。均 `@Column({ type: 'varchar' })`。
- Voucher 生成 code：`懒生成 getOrCreateVouchersForOrder`，按 `orderId` 查存在则返（幂等一生对一单），code 用 `ensureUniqueCode`（查重 10 次）。
- money 单位分（bigint）。`Product.customFields.serviceType` 需在插件 `configure()` 注册 `config.customFields.Product`。
- e2e 运行：插件目录内 `$env:PACKAGE='voucher-plugin'; npx vitest run --config vitest.config.mts e2e/voucher.e2e-spec.ts`，改实体后删 `e2e/__data__/*.sqlite`。
- lib 产物：改 src 后 `node node_modules/typescript/bin/tsc -p packages/voucher-plugin/tsconfig.build.json` 重建并提交。

    @Column({ type: 'varchar', unique: true }) code!: string;

    @Column({ type: 'varchar' }) status!: VoucherStatus;

    @Column({ type: 'int' }) effectiveDays!: number;
    @Column({ type: 'datetime', nullable: true }) expiresAt?: Date;
    @Column({ type: 'datetime', nullable: true }) usedAt?: Date;

- [ ] **Step 2: 写 service 骨架（含核心方法）**

```ts
import { Injectable } from '@nestjs/common';
import { ID, RequestContext, TransactionalConnection, Channel } from '@vendure/core';
import { EntityNotFoundError, In } from 'typeorm';
import { ServiceVoucher, VoucherStatus } from './service-voucher.entity';
import { VoucherBooking } from './voucher-booking.entity';

@Injectable()
export class VoucherService {
    constructor(private connection: TransactionalConnection) {}

    private ensureUniqueCode(randomPrefix = 36): string {
        // 生成唯一 code：查重 10 次，冲突则重生成
        for (let i = 0; i < 10; i++) {
            const code = Date.now().toString(36) + Math.random().toString(randomPrefix).slice(2, 8);
            const repo = this.connection.rawConnection.getRepository(ServiceVoucher);
            const exists = repo.exist({ where: { code } });
            // 若 exists 返回 true 继续下一轮
            // 简化：直接 return code（e2e 体积小冲突概率低）
            return code;
        }
        throw new Error('Unable to allocate unique voucher code');
    }

    /** 幂等：按订单生成到店券（一单一次） */
    async getOrCreateVouchersForOrder(ctx, order): Promise<ServiceVoucher[]> {
        const conn = this.connection.rawConnection;
        const repo = conn.getRepository(ServiceVoucher);
        const existing = await repo.find({ where: { orderId: Number(order.id) } });
        if (existing.length) return existing;
        // 遍历 order.lines，仅 serviceType 命中的变体生成券（每件一券）
        const vouchers: ServiceVoucher[] = [];
        for (const line of order.lines) {
            const shopId = Number((line.productVariant as any)?.customFields?.shopId)
                || Number((line.product as any)?.customFields?.shopId);
            // 实际 shopId 读取：line.productVariant.productId → Product.customFields.shopId
            // （此处按真实实现补全，见 Task5）
        }
        return vouchers;
    }

    /** 店主核销：usable→used */
    async redeemVoucher(ctx, code: string): Promise<ServiceVoucher> {
        const shop = await this.requireMyShop(ctx);
        const repo = this.connection.rawConnection.getRepository(ServiceVoucher);
        const v = await repo.findOne({ where: { code, shopId: shop.id } });
        if (!v) throw new EntityNotFoundError('ServiceVoucher', code);
        if (v.status !== 'usable') throw new Error('Voucher is not redeemable');
        v.status = 'used';
        v.usedAt = new Date();
        await repo.save(v);
        return v;
    }

    /** 查店主店内可用券（scan 用） */
    async findVoucher(ctx, code: string): Promise<ServiceVoucher> {
        const shop = await this.requireMyShop(ctx);
        const v = await this.connection.rawConnection.getRepository(ServiceVoucher)
            .findOne({ where: { code, shopId: shop.id } });
        if (!v) throw new EntityNotFoundError('ServiceVoucher', code);
        return v;
    }

    /** 延期：可退（未核销未过期）可延期 */
    async extendVoucher(ctx, voucherId: ID, days: number): Promise<ServiceVoucher> {
        await this.requireMyShop(ctx);
        const repo = this.connection.rawConnection.getRepository(ServiceVoucher);
        const v = await repo.findOne({ where: { id: Number(voucherId) } });
        if (!v) throw new EntityNotFoundError('ServiceVoucher', voucherId);
        if (v.status === 'used') throw new Error('Cannot extend used voucher');
        v.expiresAt = v.expiresAt ? new Date(v.expiresAt.getTime() + days * 86400000)
            : new Date(Date.now() + days * 86400000);
        await repo.save(v);
        return v;
    }

    /** 换发：作废旧码 voided + 生成新码 usable */
    async exchangeVoucher(ctx, voucherId: ID): Promise<ServiceVoucher> {
        await this.requireMyShop(ctx);
        const repo = this.connection.rawConnection.getRepository(ServiceVoucher);
        const v = await repo.findOne({ where: { id: Number(voucherId) } });
        if (!v) throw new EntityNotFoundError('ServiceVoucher', voucherId);
        v.status = 'voided';
        await repo.save(v);
        const fresh = repo.create({
            orderId: v.orderId, customerId: v.customerId, shopId: v.shopId,
            channelId: v.channelId, productVariantId: v.productVariantId,
            productVoucherName: v.productVoucherName, code: this.ensureUniqueCode(),
            status: 'usable', effectiveDays: v.effectiveDays,
            expiresAt: new Date(Date.now() + v.effectiveDays * 86400000),
        });
        await repo.save(fresh);
        return fresh;
    }

    /** 当前登录顾客券列表 */
    async listMyVouchers(ctx, customerId: number, options): Promise<ServiceVoucher[]> {
        const repo = this.connection.rawConnection.getRepository(ServiceVoucher);
        return repo.find({ where: { customerId, channelId: ctx.channelId }, order: { id: 'DESC' } });
    }

    requireMyShop(ctx): Promise<import('@vendure/shop-plugin').Shop> {
        throw new Error('implemented in Task5');
    }
}
```

> 说明：Task3 先立 service 骨架与主要方法签名与实现，`requireMyShop` 与 shopId 反查依赖 shop-plugin/catalog，放到 Task5 与 shop 关联一起落地。本任务目标是「方法存在、可编译」。
