# 阶段16 · 实施计划（商品评价体系）

依据：`2026-08-21-本地电商就近履约阶段16设计-商品评价体系.md`

## 执行顺序

### Step 1 — 实体：review.entity.ts
- 新增自关联：
  - `@OneToMany(() => Review, r => r.parent) followUps: Review[];`
  - `@ManyToOne(() => Review, r => r.followUps, { nullable: true }) parent: Review;`（FK 列名 `parentId`，TypeORM 默认命名）

### Step 2 — 类型：types.ts
- `ReviewPluginOptions`：加 `minContentLength?: number`（默认 0）、`autoApprove?: boolean`（默认 false）。
- 新增 `UpdateReviewInput` / `FollowUpReviewInput`；`CreateReviewInput.rating` 保持 `required`（主评），追评复用独立 input。

### Step 3 — 服务：review.service.ts
- 注入 `ProductService`。
- `createReview`：content 去空白 + `minContentLength` 校验；`autoApprove && status='pending'` → 置 `approved` 并 `recomputeProductRating`。
- 新增方法：
  - `createFollowUpReview(ctx, reviewId, input)`：解析归属 → 主评存在且非 deleted → 作者须与主评 `customerId` 一致 → content/rating 校验 → 存 `parentId`。
  - `updateReview(ctx, id, input)`：作者比对 → 仅 `pending/approved` → 更新字段 → 原为 approved 则重算评分。
  - `deleteReview(ctx, id)`：作者比对 → `status='deleted'` → 原为 approved 则重算评分。
  - `recomputeProductRating(ctx, productId)`：查 approved 主评 → avg/reviewCount → 写 `product.customFields.rating/reviewCount`（`productService.update`）。
  - `getProductRating(ctx, productId)`：读 Product 自定义字段。
  - `getReviewFollowUps(ctx, review)`：返回该主评 approved 追评。
- `approveReview` / `rejectReview`：approve 后重算；reject 后重算（排除）。
- `getProductReviews` / `getReviewStats`：过滤 `status='approved'` 且 `parentId IS NULL`；状态候选排除 deleted。

### Step 4 — 插件：plugin.ts
- `configuration`：`config.customFields.Product` 幂等并入 `rating`(float) / `reviewCount`(int)，均为 public:true。
- shopSchema：新增 UpdateReviewInput / FollowUpReviewInput / ProductRating；Review 加 `parentId`、`followUps`;Query 加 `productRating`;Mutation 加 `updateReview`/`deleteReview`/`createFollowUpReview`。
- adminSchema：Review 加 `parentId`、`followUps`；Query 加 `productRating`。
- 两个 Resolver 各加 `followUps`/`productRating` 解析。
- 新增 `product-custom-fields.ts`（命名对齐 flash-sale 的 order-custom-fields.ts），含 `mergeCustomFields` 复用（复用 flash-sale-plugin 同级工具或本地实现）。

### Step 5 — Resolver：
- review-shop.resolver.ts：加 `updateReview` / `deleteReview` / `createFollowUpReview` / `productRating` / `followUps` ResolveField。
- review-admin.resolver.ts：加 `productRating` / `followUps` ResolveField。

### Step 6 — 工程脚手架（对齐 flash-sale-plugin）：
- `vitest.config.mts`
- `tsconfig.build.json`
- `e2e/review.e2e-spec.ts`（含 `e2e/__data__/`，sqljs 缓存库）
- index.ts 保持现有导出（新增 `product-custom-fields`/types 导出可选）。

### Step 7 — e2e 用例（标题含中文，口径：pricesIncludeTax=true）

| # | 用例 | 断言要点 |
|---|---|---|
| 1 | 插件可加载；Product 字段默认 rating=0/reviewCount=0 | productRating 为 0/0 |
| 2 | 评价订单商品：Delivered 后可建（pending）；未送达拦截；重复拦截 | 状态 pending；错误拦截 |
| 3 | 审核后对外可见+聚合更新 | approve 后 productReviews 1 条、rating 更新 |
| 4 | 追评不计分但挂主评下 | followUps 1 条；聚合/列表数不变 |
| 5 | 修改：作者改评分聚合随之变化；非作者 Forbidden | avg 变化；他人改抛错 |
| 6 | 删除：作者删后列表/聚合剔除 | deleted 不计分；productReviews 0 |
| 7 | 屏蔽刷评：minContentLength 拦截；他人 orderLine 拦截 | 抛错误 |
| 8 | 匿名：customerName null 但计入聚合 | 名脱敏、平均分含匿名评分 |
