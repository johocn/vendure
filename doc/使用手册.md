# Vendure 后端使用手册

## 1. 环境准备

### 1.1 系统要求

| 组件 | 版本要求 | 说明 |
|------|---------|------|
| Node.js | >= 20.x | LTS 版本推荐 |
| PostgreSQL | >= 14 | 主数据库 |
| Redis | >= 6 | 可选，用于库存扣减 |
| npm | >= 9 | 包管理器 |

### 1.2 数据库配置

编辑 `packages/dev-server/.env`：

```env
DB=postgres
DB_HOST=127.0.0.1
DB_PORT=5432
DB_USERNAME=postgres
DB_PASSWORD=admin
DB_NAME=vendure
```

也支持 MySQL/MariaDB 和 SQLite：
- `DB=mysql` — 使用 MariaDB（默认配置 127.0.0.1:3306）
- `DB=sqlite` — 使用 SQLite（文件存储，适合快速测试）

## 2. 启动与运行

### 2.1 启动开发服务器

```bash
cd e:/code/vendure/packages/dev-server
npm run dev:server
```

服务启动后可访问：

| 地址 | 说明 |
|------|------|
| http://localhost:3000/shop-api | Shop GraphQL API |
| http://localhost:3000/admin-api | Admin GraphQL API |
| http://localhost:3000/graphiql/shop | Shop API GraphiQL 调试 |
| http://localhost:3000/graphiql/admin | Admin API GraphiQL 调试 |
| http://localhost:3000/admin | Admin UI 管理后台 |
| http://localhost:3000/dashboard | 数据仪表盘 |
| http://localhost:3000/mailbox | 开发邮箱（邮件预览） |
| http://localhost:3000/assets | 资源文件服务 |

### 2.2 启动 Worker（后台任务）

```bash
cd e:/code/vendure/packages/dev-server
npm run dev:worker
```

Worker 处理后台任务（定时任务、邮件发送、订单超时等）。

### 2.3 同时启动 Server + Worker

```bash
cd e:/code/vendure/packages/dev-server
npm run dev
```

## 3. 插件配置参考

### 3.1 环境变量完整清单

编辑 `packages/dev-server/.env`：

```env
# ── 数据库 ──
DB=postgres
DB_HOST=127.0.0.1
DB_PORT=5432
DB_USERNAME=postgres
DB_PASSWORD=admin
DB_NAME=vendure

# ── 微信认证 ──
WECHAT_AUTH_APP_ID=             # 公众号 AppID
WECHAT_AUTH_APP_SECRET=         # 公众号 AppSecret
WECHAT_AUTH_MINI_APP_ID=        # 小程序 AppID（可选）
WECHAT_AUTH_MINI_APP_SECRET=    # 小程序 AppSecret（可选）

# ── 手机验证码（阿里云短信） ──
SMS_ACCESS_KEY_ID=              # 阿里云 AccessKey ID
SMS_ACCESS_KEY_SECRET=          # 阿里云 AccessKey Secret
SMS_SIGN_NAME=                  # 短信签名
SMS_TEMPLATE_CODE=              # 短信模板代码

# ── 微信支付 ──
WECHATPAY_NOTIFY_URL=           # 微信支付回调地址

# ── 支付宝 ──
ALIPAY_NOTIFY_URL=              # 支付宝回调地址
ALIPAY_PUBLIC_KEY=              # 支付宝公钥

# ── 阿里云 OSS ──
OSS_REGION=                     # OSS 区域
OSS_ACCESS_KEY_ID=              # AccessKey ID
OSS_ACCESS_KEY_SECRET=          # AccessKey Secret
OSS_BUCKET=                     # Bucket 名称

# ── 物流（快递100） ──
KUAIDI100_CUSTOMER=             # 快递100 customer
KUAIDI100_KEY=                  # 快递100 key

# ── Redis ──
REDIS_URL=                      # Redis 连接 URL

# ── 开发模式 ──
DEV_BYPASS_SMS=true             # 手机验证码 bypass（固定 123456）
DEV_BYPASS_WECHAT=true          # 微信认证 bypass（测试 AppID）
```

### 3.2 插件条件加载

dev-config.ts 中插件按需加载，只有配置了对应环境变量才会启用：

```typescript
// 有环境变量 → 加载插件
...(process.env.WECHAT_AUTH_APP_ID ? [WechatAuthPlugin.init({...})] : []),

// 有环境变量 OR dev bypass → 加载插件
...((process.env.SMS_ACCESS_KEY_ID || process.env.DEV_BYPASS_SMS === 'true')
    ? [PhoneAuthPlugin.init({...})] : []),

// 无条件加载
OrderTimeoutPlugin.init({ defaultTimeoutMinutes: 30 }),
```

### 3.3 业务插件配置项速查

| 插件 | init 参数 | 默认值 |
|------|----------|--------|
| DistributionPlugin | defaultDirectRate, defaultIndirectRate, minWithdrawalAmount, settlementDays | 1000, 500, 10000, 7天 |
| GroupBuyPlugin | defaultTimeoutMinutes | 60 |
| FlashSalePlugin | defaultTimeoutMinutes | 15 |
| OrderTimeoutPlugin | defaultTimeoutMinutes | 30 |
| RechargeCardPlugin | defaultExpiresMonths | 12 |
| AfterSalesPlugin | maxDaysAfterDelivery | 15 |

## 4. GraphQL API 速查

### 4.1 认证

```graphql
# 手机验证码发送
mutation { sendPhoneVerificationCode(phoneNumber: "13800138000") }

# 手机验证码登录
mutation {
  authenticate(input: { phone: { phoneNumber: "13800138000", code: "123456" } }) {
    ... on CurrentUser { id identifier }
  }
}

# 微信登录
mutation {
  authenticate(input: { wechat: { code: "oauth_code", type: "mp" } }) {
    ... on CurrentUser { id identifier }
  }
}

# 账号密码登录
mutation {
  login(username: "user", password: "pass") {
    ... on CurrentUser { id identifier }
  }
}

# 退出登录
mutation { logout { success } }
```

### 4.2 JS-SDK 签名

```graphql
query {
  wechatJsapiSignature(url: "https://shop.example.com/page") {
    appId
    timestamp
    nonceStr
    signature
  }
}
```

### 4.3 商品 / 购物车 / 订单

```graphql
# 商品列表
query { products(options: { take: 10 }) { items { id name slug priceWithTax } } }

# 商品详情
query { product(slug: "product-slug") { id name description priceWithTax } }

# 加入购物车
mutation { addItemToCart(productId: 1, quantity: 1) { id lines { quantity } } }

# 创建订单
mutation { transitionOrderToState(state: "ArrangingPayment") { ... on Order { id } } }

# 支付
mutation { transitionOrderToState(state: "PaymentSettled") { ... on Order { id } } }
```

## 5. 微信生态配置

### 5.1 微信公众号

1. 登录 [微信公众平台](https://mp.weixin.qq.com/)（需已认证服务号）
2. **开发** → **基本配置** → 获取 AppID 和 AppSecret
3. **开发** → **接口权限** → **网页授权** → 设置授权回调域名
4. **开发** → **基本配置** → **IP 白名单** → 添加服务器 IP
5. **公众号设置** → **功能设置** → **JS接口安全域名** → 设置 JS-SDK 域名

### 5.2 微信小程序

1. 登录 [微信公众平台](https://mp.weixin.qq.com/) → 小程序
2. **开发** → **开发管理** → **开发设置** → 获取 AppID 和 AppSecret
3. **服务器域名** → 将 API 域名添加到 request 合法域名

### 5.3 微信支付

1. 登录 [微信商户平台](https://pay.weixin.qq.com/)
2. 获取商户号、API 密钥、证书
3. 配置支付回调 URL

### 5.4 支付宝

1. 登录 [支付宝开放平台](https://open.alipay.com/)
2. 创建应用，获取 AppID
3. 配置 RSA2 密钥对
4. 设置回调地址

## 6. 部署指南

### 6.1 生产构建

```bash
# 编译所有插件
cd e:/code/vendure
npx lerna run build --scope '@vendure/*'

# 或逐个编译关键插件
cd packages/wechat-auth-plugin && npm run build
cd packages/phone-auth-plugin && npm run build
# ...
```

### 6.2 生产环境变量清单

生产环境必须配置的环境变量：

| 变量 | 必须 | 说明 |
|------|------|------|
| DB, DB_HOST, DB_PORT, DB_USERNAME, DB_PASSWORD, DB_NAME | 是 | 数据库连接 |
| WECHAT_AUTH_APP_ID, WECHAT_AUTH_APP_SECRET | 是（微信登录） | 微信公众号凭证 |
| SMS_ACCESS_KEY_ID, SMS_ACCESS_KEY_SECRET, SMS_SIGN_NAME, SMS_TEMPLATE_CODE | 是（手机登录） | 阿里云短信 |
| WECHATPAY_NOTIFY_URL | 是（微信支付） | 支付回调 |
| OSS_REGION, OSS_ACCESS_KEY_ID, OSS_ACCESS_KEY_SECRET, OSS_BUCKET | 是（文件上传） | OSS 存储 |

### 6.3 数据库迁移

```bash
# 生成迁移
cd packages/dev-server
npx ts-node migration.ts generate

# 运行迁移
npx ts-node migration.ts run

# 回滚迁移
npx ts-node migration.ts revert
```

### 6.4 安全注意事项

- **不要** 将 AppSecret / AccessKey 提交到 Git
- 生产环境设置 `DEV_BYPASS_SMS` 和 `DEV_BYPASS_WECHAT` 为空
- 启用 HTTPS
- 配置 CORS 白名单
- 定期更换密钥
